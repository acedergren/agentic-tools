# Marquee Swedish Dialects

Use this file when the user asks for regional voice, dialect flavor, or playful Swedish. Dialect is primarily spoken; written dialect is always a stylization. Prefer light flavor over heavy eye-dialect unless the user explicitly asks for performance, comedy, fiction, or dialogue.

## Dialect Flavor Rules

- Start with purpose: local warmth, character voice, joke, brand tone, or linguistic explanation.
- Keep the base text grammatical and understandable to a national Swedish reader.
- Use 1-3 features per short text. More quickly becomes costume.
- Prefer local words, rhythm, and a few sound hints over spelling every word phonetically.
- Avoid mocking pronunciations tied to class, age, or rural/urban stereotypes.
- State uncertainty when the user wants a real local dialect and the source is broad regional data.
- For public, customer, or professional text, usually use standard Swedish with one local wink.

## Linköping / Östgötska

Use for the user's home dialect, especially when the request mentions Linköping, Östergötland, Östgötska, or an East-Central Swedish local flavor.

### Source-Grounded Profile

- Östergötland sits at a dialect boundary. Isof describes most of Östergötland as belonging to the mellansvenska/sveamål area, while the southwest has stronger götamål traits.
- In central/western Östergötland, including the Linköping and Mjölby area, final `-a` often weakens toward `-ä`: `stuga` -> `stugä`, `kasta` -> `kastä`.
- Eastern Östergötland more often weakens final `-a` toward `-e`, while the southwest can preserve `-a`.
- The dialect has strong local variation. Linköping city Swedish is not identical to rural Östgötska.

### Safe Writing Moves

- Use standard Swedish as the base and add a few Östgöta markers.
- Let final `-a` -> `-ä` appear sparingly in dialogue or playful local copy: `kastä`, `stugä`, `pratä`.
- Use a calm, dry, slightly underplayed tone; it usually lands better than exaggerated dialect spelling.
- Add local place anchors when relevant: Linköping, Stångån, Tinnerö, universitetet, SAAB, slätten, E4:an.
- Consider one local word when it fits. `Träligt` can mean boring, troublesome, or tiresome in regional/everyday Swedish.

### Avoid

- Do not turn every `a` into `ä`.
- Do not write a full comic transcription unless the user asks for comedy.
- Do not claim there is one canonical Linköping spelling.
- Do not overuse `öschöttska`-style spelling unless the user explicitly wants a self-aware dialect bit.

### Example

Neutral:

> Vi ses vid Stångån efter jobbet. Jag tar med kaffe om du fixar bullarna.

Light Linköping/Östgöta flavor:

> Vi ses vid Stångån efter jobbet. Jag tar med kaffe, så kan du fixä bullarna. Blir fint dä.

Use the second style only for informal, playful contexts.

## Göteborgska

Use when the text should feel west-coast, quick, warm, and a little dryly humorous.

- Use a relaxed rhythm and understated punchline rather than heavy phonetic spelling.
- Carefully chosen local words can work in playful contexts: `go`, `gött`, `la`, `änna`.
- Göteborgska has recognizable vowel and pitch patterns that are hard to write without overdoing it.
- Avoid turning every line into a joke. The dialect can sound friendly without being comic.

Example:

> Det här blir gött. Vi skeppar när testerna är gröna, inte en minut innan.

## Skånska

Use when the text should signal southern Sweden or Skåne.

- Skånska has strong pronunciation traits, including southern `r` patterns and vowel qualities, but written imitation gets heavy fast.
- Use place, rhythm, and a few lexical choices before phonetic respelling.
- For readable dialogue, keep standard spelling and add only a light marker such as `ja`, `nä`, or a local place anchor.
- Avoid exaggerated `r` jokes or making the voice hard to read.

Example:

> Vi tar det lugnt, kör igenom riskerna och släpper först när allt håller.

## Gotländska

Use when the text should feel island-specific, warm, and distinctive.

- Gotland has distinctive melody and vowel/diphthong traits that are difficult to represent cleanly in writing.
- Use place anchors such as Visby, havet, raukar, färjan, Almedalen, or socken names when relevant.
- Use very light sound hints only in dialogue; otherwise keep standard Swedish.
- Avoid generic pirate/island caricature.

Example:

> Vi tar färjan när allt är klart. Ingen stress, men det ska hålla hela vägen.

## Norrländska Mål

Use only as a broad regional flavor unless the user names a specific place. Northern Swedish is not one dialect.

- Understatement and pauses often carry the flavor better than misspelling.
- `Vars` and `he` can be regionally marked, but use them only when they fit the speaker and context.
- Avoid treating all of northern Sweden as one voice.

Example:

> Jo, det där blir nog bra. Vi kör när bygget är grönt.

## Dalmålsfärg

Use when the user asks for Dalarna specifically, but be extra careful. Dalarna has many highly local dialects and several are difficult to stylize responsibly without local knowledge.

- Prefer place anchors such as Mora, Rättvik, Leksand, Falun, Siljan, or byn if context allows.
- Keep standard Swedish unless the user provides a specific local model.
- Avoid generic old-timey Swedish.
